Laboratório - Fazer as perguntas certas​

Objetivos
Este laboratório oferece oportunidades para os alunos iniciarem um projeto de análise pessoal.

Escolha um tópico para investigar.

Formule uma pergunta para responder com a análise.

Determine os elementos de dados necessários para encontrar as respostas.

Histórico / Cenário
Neste laboratório, você começará seu primeiro projeto analítico, começando com a etapa "Faça a pergunta" do processo. Escolha um tópico do seu interesse e que você queira ver até o fim. Na maioria dos projetos de análise de dados, há uma necessidade ou um benefício identificado que informa a pergunta que inicia o processo. A pergunta determina que tipo de análise e quais elementos de dados são necessários para produzir os resultados desejados.

Depois de formular uma pergunta, você pode fazer hipóteses sobre o resultado da análise. Depois de concluir a análise, mais adiante no curso, você poderá comparar a hipótese inicial com o resultado real.

Recursos necessários
Um dispositivo com um navegador de Internet e uma conexão com a Internet.
Instruções
Parte 1: Determine um tópico
Você já se perguntou sobre algo para o qual não conseguiu encontrar uma resposta ou estava cético em relação às respostas que encontrou? Os tópicos sobre os quais você deseja saber mais são excelentes opções para seu primeiro projeto analítico.

Etapa 1: Fazer uma pergunta

Pode ser algo tão simples quanto “ter o Batman aparecendo no filme o torna mais bem-sucedido nas bilheterias?” ou "quais sabores de sorvete são mais populares em diferentes faixas etárias?". Ou pode ser algo mais complexo, como “qual criptomoeda é o melhor investimento de acordo com o desempenho do ano passado?”.

Anote sua pergunta. Qual é a vantagem de determinar a resposta a essa pergunta? Na maioria dos projetos de análise de dados, o benefício potencial é o motivo do projeto. Por exemplo, um executivo de marketing se beneficiaria ao saber quais faixas etárias preferem determinados sabores de sorvete, pois isso pode ajudar a determinar onde colocar a publicidade ou quais sabores estocar em cidades com faculdades ou universidades.
Analise os quatro tipos diferentes de análise de dados descritos no módulo. Que tipo de análise você acha que é melhor para descobrir a resposta para sua pergunta? Na maioria dos casos, a análise descritiva é uma boa escolha se a resposta for determinada pela análise de dados históricos.
Etapa 2: Determinar os dados necessários

Agora que você tem uma pergunta em mente, pense nos elementos de dados que talvez seja necessário analisar para encontrar uma resposta para a pergunta.

Faça uma lista dos elementos de dados identificados. Um exemplo: se a pergunta for “ter o Batman aparecendo no filme o torna mais bem-sucedido nas bilheterias?”, alguns dos elementos de dados necessários seriam:
Filmes com o Batman como personagem
Filmes de sucesso feitos no mesmo período
Vendas de bilheteria e receita de filmes no mesmo período
Abra um navegador da Web e use qualquer mecanismo de pesquisa para pesquisar os elementos de dados que você identificou.
Liste as fontes encontradas que podem ter dados relacionados aos elementos identificados.
Você também pode investigar fontes, como a Kaggle, que fornecem dados de exemplo para análise.
