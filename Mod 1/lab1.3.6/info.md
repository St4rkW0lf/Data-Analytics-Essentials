# Laboratório - Requisitos do portfólio de pesquisa

## Objetivos

Neste laboratório, você explorará os portfólios de analistas de dados e criará uma lista de verificação para demonstrar as habilidades dos analistas de dados.

* **Parte 1:** Portfólios de analistas de dados de pesquisa.
* **Parte 2:** Lista de verificação de habilidades de criação de analistas de dados.
* **Parte 3:** Configuração de um repositório GitHub para o portfólio.

---

# Histórico / Cenário

Um portfólio de análise de dados destaca seu trabalho e exibe sua marca pessoal e habilidades de comunicação.

Um analista de dados também precisa ter um plano para desenvolver as habilidades necessárias e para realizar e apresentar seus projetos a possíveis empregadores.

Use este laboratório como ponto de partida para iniciar o portfólio de analistas de dados. À medida que avança no curso, você pode usar as atividades do curso para criar seu primeiro projeto analítico.

---

# Recursos necessários

* Dispositivo móvel ou PC/laptop;
* Navegador da Web;
* Conexão com a Internet.

---

# Instruções

## Parte 1: Portfólios de analistas de dados de pesquisa

### Etapa 1: Procure portfólios de analistas de dados

1. Usando um navegador da Web, pesquise **"exemplo de portfólio de ciência de dados"**.
2. Selecione alguns portfólios, leia e observe a variedade de estilos de conteúdo e apresentação.

Um site que examina exemplos de portfólio é o [CareerFoundry](https://careerfoundry.com/en/blog/data-analytics/data-analytics-portfolio-examples/).

---

### Etapa 2: Listar possíveis projetos

Faça uma lista de alguns dos projetos interessantes destacados nos portfólios visualizados.

Inclua também projetos em que você possa estar interessado, aqueles em que gostaria de realizar pesquisas de dados, como:

* Hobbies;
* Esportes;
* Entretenimento;
* Literatura;
* Tecnologia;
* Finanças;
* Outros interesses pessoais.

---

### Etapa 3: Considere possíveis estilos de portfólio

Considere como você pode apresentar os projetos no portfólio.

Selecione um estilo que reflita sua personalidade e seus objetivos.

Examine os exemplos encontrados para determinar:

* Estilos de mídia;
* Organização do conteúdo;
* Layout;
* Apresentação dos projetos;
* Forma de exposição dos resultados;
* Recursos visuais utilizados.

O objetivo é escolher uma apresentação que represente suas habilidades e seja adequada às expectativas de um possível empregador.

---

### Etapa 4: Crie uma lista de verificação de portfólio

1. Desenvolva uma lista de verificação dos componentes observados nos portfólios analisados.
2. À medida que você trabalha nas atividades do curso, atualize a lista de verificação ao concluir cada item.

# Parte 2: Lista de verificação de habilidades de criação de analistas de dados

## Etapa 1: Procure qualificações profissionais de analista de dados

Pesquise na Internet empregos de analista de dados em seu país ou região específica.

Um site que pode ser considerado é o [ZipRecruiter](https://www.ziprecruiter.com/n/Data-Analyst-Jobs-Near-Me).

Sites como o [Thinkful](https://www.thinkful.com/blog/entry-level-data-analyst/) também podem ser utilizados como referência.

Observe os requisitos de trabalho e as habilidades essenciais para analistas de dados iniciantes ou juniores.

Algumas habilidades a serem procuradas incluem:

* SQL;
* Microsoft Excel;
* Estatística;
* Visualização de dados;
* Habilidades de comunicação e apresentação;
* Pensamento crítico.

É importante separar como essas habilidades se relacionam com as funções de nível básico e com as expectativas de funções mais experientes.

---

## Etapa 2: Crie uma lista de verificação das habilidades do analista de dados

Crie uma lista de verificação dos requisitos de trabalho para a função de analista de dados.

À medida que você aprende e pratica cada habilidade, observe seu nível de proficiência. Pode ser utilizada uma escala como:

* **Nenhuma**;
* **Básica**;
* **Intermediária**;
* **Avançada**.

Atualize continuamente o currículo e o portfólio à medida que avança na lista de verificação.

# Parte 3: Configuração de um repositório GitHub para o portfólio

O GitHub é uma plataforma de hospedagem que oferece colaboração e serviço de controle de versão para indivíduos e empresas.

Nesta parte, você criará uma conta pessoal do GitHub e um repositório para seu uso.

---

## Etapa 1: Conhecer o GitHub

1. Navegue até a [Documentação do GitHub](https://docs.github.com/) ou pesquise **"github documentation"** usando um navegador da Web.
2. Clique em **Introdução** para analisar alguns dos recursos básicos do GitHub.

### Questões

**Quais tipos de contas (produtos) estão disponíveis no GitHub?**

**O que você pode fazer com uma conta pessoal?**

---

## Etapa 2: Crie uma conta pessoal

Uma conta do GitHub é necessária para criar um repositório.

Um **repositório** é onde você pode organizar um projeto e armazenar os arquivos e as pastas relacionados a ele.

Nesta etapa, você criará uma conta pessoal do GitHub.

1. Navegue até o [GitHub](https://github.com/) para se inscrever em uma conta.

   > **Observação:** Se você já tiver uma conta do GitHub, verifique se já saiu da conta.

2. No campo **Endereço de e-mail**, insira um endereço de e-mail válido e clique em **Inscreva-se no GitHub** para prosseguir para a tela de boas-vindas.

3. Na tela de boas-vindas:

   * Verifique seu endereço de e-mail;
   * Crie uma senha;
   * Insira um nome de usuário;
   * Responda à pergunta sobre o recebimento de produtos e atualizações por e-mail;
   * Resolva os desafios de verificação.

4. Clique em **Criar Conta** para criar o novo usuário.

5. Você receberá um código do GitHub no endereço de e-mail fornecido.

6. Insira o código de inicialização fornecido para concluir a criação da conta.

7. Responda aos prompts pessoais e clique em **Continuar**.

8. Clique em **Continuar** na tela do recurso sem fazer seleções.

9. Clique em **Continuar gratuitamente** depois de analisar os recursos da conta gratuita.

---

## Etapa 3: Crie um novo repositório privado

Agora que você possui uma conta de usuário, criará um novo repositório privado.

1. Faça login no GitHub usando a nova conta de usuário, conforme necessário.
2. Clique em **Criar um novo repositório**.
3. Insira um nome de repositório de sua escolha no campo **Nome do repositório**.
4. Forneça uma descrição do repositório, se desejado.
5. Selecione **Privado** para criar um repositório privado.
6. Selecione **Adicionar um arquivo README**.
7. Clique em **Criar Repositório** para continuar.

---

## Etapa 4: Gerencie os arquivos no repositório

Os arquivos podem ser carregados no repositório ou criados diretamente nele.

Se você já tiver criado um arquivo `README`, poderá copiar o conteúdo para o arquivo README existente no repositório.

Nesta etapa, você carregará um arquivo no repositório.

Para obter mais informações sobre gerenciamento de arquivos, consulte a [documentação do GitHub sobre repositórios](https://docs.github.com/en/repositories).

1. No repositório recém-criado, clique em **Adicionar arquivo** > **Carregar arquivos** para carregar um novo arquivo na guia **Código**.
2. Você pode arrastar os arquivos para a área indicada ou clicar em **escolher os arquivos** para adicioná-los ao repositório.
3. Clique em **Confirmar alterações** para salvar as alterações diretamente na filial principal.

# Atividades de desafio

O projeto do telescópio **Square Kilometer Array (SKA)** ([SKA Project](https://www.skatelescope.org/the-ska-project/)) e o telescópio **James Webb** ([NASA — James Webb Space Telescope](https://www.nasa.gov/mission_pages/webb/main/index.html)) são projetos de astronomia de muito longo prazo que produzirão volumes de dados quase inimagináveis durante a vida útil de cada projeto.

Pense nas habilidades de dados que terão que ser aplicadas para analisar esses dados e quais processos podem ter que ser desenvolvidos para gerenciar essa análise no futuro.

Considere aspectos como:

* Armazenamento de grandes volumes de dados;
* Processamento e limpeza de dados;
* Automação;
* Análise estatística;
* Inteligência artificial e aprendizado de máquina;
* Visualização de dados;
* Computação de alto desempenho;
* Colaboração entre pesquisadores;
* Segurança e gerenciamento de dados;
* Desenvolvimento de novos métodos de análise.
